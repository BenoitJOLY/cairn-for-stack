StackForge V4 — Guide enseignant

Créer, personnaliser et exporter des questions STACK pour Moodle — sans écrire de code

Version 4.1 · 2026 40+ types de questions

1. Introduction

StackForge V4 est un outil de création de questions STACK pour Moodle. STACK (System for Teaching and Assessment using a Computer algebra system) évalue automatiquement des réponses mathématiques et scientifiques grâce au moteur de calcul formel Maxima.

Avec StackForge, vous concevez vos questions dans une interface visuelle et vous exportez un fichier XML prêt à importer dans Moodle — sans écrire une seule ligne de code STACK.

Ce qu'StackForge fait pour vous
  • Génère les variables Maxima (ta1, ta2…) et les randomise
  • Construit l'arbre de réponse (PRT) adapté à chaque type
  • Produit le XML STACK importable directement dans Moodle
  • Sauvegarde automatiquement votre travail dans le navigateur
  • Permet de créer plusieurs questions dans un même quiz

2. Démarrage rapide

Ouvrez index.html dans votre navigateur (Chrome ou Firefox recommandé). Aucune installation requise.
Donnez un nom à votre exercice dans le champ Nom de l'exercice en haut de page.
Cliquez sur + Ajouter une question. Une palette de types apparaît — choisissez celui qui correspond à votre objectif pédagogique.
Remplissez le panneau de configuration à droite : énoncé, réponse, feedback.
Cliquez sur Enregistrer (le chip de la question passe au vert).
Répétez pour chaque question, puis cliquez sur Exporter XML pour télécharger le fichier à importer dans Moodle.
Sauvegarde automatique
Votre travail est enregistré automatiquement dans le navigateur après chaque modification. L'indicateur en bas de page confirme la sauvegarde. Pour transférer votre travail sur un autre poste, utilisez Exporter projet (.stackforge).

3. L'interface V4

Zone d'édition (centre)

L'éditeur principal contient vos questions sous forme de chips (pastilles colorées). Chaque chip représente une question :

  • Chip grise — non configurée (brouillon)
  • Chip verte — configurée et valide
  • Chip orange — modifiée mais non enregistrée

Cliquez sur une chip pour ouvrir son panneau de configuration. Faites glisser les chips pour réordonner les questions dans le quiz.

Barre d'en-tête

  • Nom de l'exercice — apparaîtra dans Moodle comme catégorie
  • Variables partagées — définir des variables Maxima communes à toutes les questions
  • Exporter XML — générer le fichier Moodle
  • Exporter projet / Importer projet — sauvegarder/charger au format .stackforge

Panneau de configuration (droite)

S'affiche au clic sur une chip. Contient tous les réglages de la question sélectionnée. Le bouton Enregistrer valide la configuration et met à jour le XML interne.

Important
Le bouton Enregistrer du panneau et l'autosauvegarde locale sont deux mécanismes distincts. L'autosauvegarde préserve l'état de l'interface ; Enregistrer valide la question et génère son XML.

Mode sombre

Un bouton de basculement clair/sombre est disponible dans le pied de page. La préférence est mémorisée entre les sessions.

4. Gestion des projets

StackForge V4 dispose d'un gestionnaire de projets permettant de travailler sur plusieurs exercices indépendants.

Slots de sauvegarde

Cliquez sur l'icône dossier dans la barre pour ouvrir le gestionnaire. Vous disposez de 5 emplacements nommés dans le localStorage :

  • Sauvegarder — enregistre l'exercice courant dans un slot
  • Charger — restaure un exercice depuis un slot
  • Supprimer — vide un slot

Export / Import portable

Pour transférer un projet entre ordinateurs ou le partager :

  • Exporter projet (.stackforge) — télécharge un fichier JSON complet
  • Importer projet (.stackforge) — restaure depuis ce fichier
Le format .stackforge contient l'intégralité de l'exercice (questions, configurations, feedback, PRT) et peut être réimporté même après une vidange du cache du navigateur.

6. Créer une question — Pas à pas

6.1 QCM (Cases / Radio / Menu)

Les trois types QCM partagent le même principe : définir des propositions et marquer lesquelles sont correctes.

Choisissez Cases à cocher, Bouton radio ou Menu déroulant.
Rédigez l'Énoncé (l'éditeur riche permet les formules LaTeX et le HTML).
Cliquez + Ajouter une proposition. Saisissez le texte. Cochez Correcte si c'est la bonne réponse.
Ajoutez autant de propositions que nécessaire. Réordonnez avec les flèches.
Pour radio/menu : assurez-vous qu'une seule proposition est cochée.
Cliquez Enregistrer. La chip passe au vert.
Mélange automatique
Les propositions sont mélangées aléatoirement pour chaque élève. L'option "Mélanger les choix" est activée par défaut.

6.2 Expression algébrique

L'élève saisit une expression mathématique vérifiée par Maxima via AlgEquiv.

Choisissez Algébrique.
Remplissez les paramètres aléatoires si besoin. Ex : rand_with_prohib(-5,5,[0]) pour un entier non nul.
Rédigez l'Énoncé avec les variables : {@ta1@} affiche la valeur, \({@ta1*x^2@}\) en LaTeX.
Saisissez la Réponse modèle en syntaxe Maxima. Ex : ta1*x^2 + 2*x - 1.
Ajoutez les feedbacks correct et incorrect.
Syntaxe Maxima obligatoire
Multiplication : 2*x (pas 2x). Puissance : x^2. Pi : %pi. Voir la section Aide-mémoire Maxima.

6.3 Réponse numérique

Choisissez Numérique.
Entrez la valeur exacte en Maxima : sqrt(2)/2, %pi/4, ou un nombre décimal.
Réglez la tolérance : 0.05 = 5 % d'erreur acceptable. Mettez 0 pour une égalité stricte.
Si besoin, précisez les chiffres significatifs attendus (min/max).

6.4 Valeur avec unité

L'élève doit donner la valeur ET l'unité. STACK vérifie la dimension physique.

Choisissez Unités physiques.
Saisissez la valeur (ex : 9.81) et l'unité SI (ex : m/s^2).
Réglez la tolérance numérique et les chiffres significatifs si nécessaire.
STACK accepte les multiples SI (km/h, kJ…) et vérifie la dimension physique : 9.81 N/kg est accepté pour 9.81 m/s^2 car dimensionnellement équivalent.

6.5 Réponse textuelle (String)

Choisissez String.
Entrez la réponse correcte (ex : Newton, Acide chlorhydrique).
Choisissez Insensible à la casse (recommandé) ou Exact.

6.6 Relier (Matching)

Choisissez Relier.
Cliquez + Ajouter une paire. Entrez le terme gauche (question) et le terme droit (réponse).
Répétez pour toutes les paires. Ajoutez des distracteurs (termes droits sans correspondance) pour augmenter la difficulté.

6.7 Mots croisés

Choisissez Mots croisés.
Cliquez + Ajouter un mot. Entrez le mot (sans accent de préférence) et sa définition.
Ajoutez 6 à 15 mots. La grille est générée automatiquement dans Moodle.
Les mots doivent partager des lettres communes pour former une grille. Privilégiez des mots de 4 à 12 lettres. Une liste de moins de 4 mots peut produire une grille vide.

6.8 Ordonnancement (Parsons)

L'élève remet des blocs dans le bon ordre par glisser-déposer. Idéal pour les algorithmes, étapes de raisonnement, chronologies.

Choisissez Ordonnancement.
Saisissez chaque élément dans l'ordre correct — l'ordre de saisie est l'ordre attendu.
Cochez Éléments réutilisables si un bloc peut apparaître plusieurs fois.

6.9 Clic sur image

L'élève clique sur la zone correcte d'un schéma. La zone cible reste invisible.

Choisissez Clic sur image.
Entrez l'URL de l'image hébergée en ligne.
Définissez la zone : Cercle (X centre, Y centre, Rayon) ou Rectangle (X1, Y1, X2, Y2). Valeurs en % de la taille de l'image.
Trouver les coordonnées : ouvrez l'image dans Paint ou GIMP, relevez les pixels du centre et du rayon, divisez par la largeur/hauteur × 100.

7. Variables partagées entre questions

Les variables partagées permettent de définir des paramètres Maxima utilisables dans toutes les questions du quiz. Idéal pour un contexte commun (un même circuit électrique, une même molécule, un même jeu de données).

Définir des variables partagées

Cliquez sur le bouton Variables partagées dans la barre d'en-tête. La syntaxe est la même que pour les variables locales :

/* Variables communes à tout le quiz */
masse : rand_with_prohib(1, 10, [0]);
vitesse : rand(5) + 3;
energie : masse * vitesse^2 / 2;
Les variables partagées sont injectées avant les variables locales de chaque question. Si une question redéfinit une variable partagée, la valeur locale prend le dessus pour cette question seulement.

9. L'arbre de réponse (PRT)

Le PRT (Potential Response Tree) est la logique de correction STACK. Il décrit comment la réponse de l'élève est évaluée, note attribuée et feedback délivré.

PRT généré automatiquement
Pour tous les types simples, StackForge crée un PRT de base : réponse correcte → 100%, incorrecte → 0%. C'est suffisant dans la plupart des cas.

Structure d'un nœud PRT

Chaque nœud effectue un test entre la réponse de l'élève (sans) et une valeur de référence (tans) :

Nœud 0 — AlgEquiv(sans1, ta1) ✓ Vrai → score =1 → FIN (feedback "Bravo !") ✗ Faux → score =0 → Nœud 1 Nœud 1 — SameType(sans1, ta1) ✓ Vrai → score =0.5 → FIN (bonne forme, mauvais coeff.) ✗ Faux → score =0 → FIN (type de réponse incorrect)

Ouvrir l'éditeur PRT

Cliquez sur PRT dans le panneau de configuration. L'éditeur s'ouvre avec :

  • Zone de l'arbre — vue graphique des nœuds et flèches (verte = vraie, rouge pointillé = fausse)
  • Panneau d'édition (droite) — modifier le nœud sélectionné
  • Barre d'outils — Tidy, Reset, + Nœud, Appliquer

Navigation dans l'arbre

  • Clic sur un nœud → ouvre son formulaire d'édition
  • Glisser un nœud → repositionner
  • Glisser le fond → sélection par zone (rectangle)
  • Molette de la souris → zoom avant/arrière
  • Boutons −/+/⊙ dans la légende → zoom manuel et réinitialisation
  • Tidy → renuméroter les nœuds séquentiellement
  • Reset → repositionner les nœuds automatiquement (centré)

PRT à score partiel — exemple

Pour donner 50% si l'élève a la bonne forme mais pas les bons coefficients :

  1. Nœud 0 : AlgEquiv(réponse, bonne réponse) → Vrai : =1 / Faux : Nœud 1
  2. Nœud 1 : SameType(réponse, modèle) → Vrai : =0.5 / Faux : =0
Règle du chemin vrai = 1
La somme des scores sur le chemin des branches vraies successives doit atteindre exactement 1. StackForge affiche un bandeau d'avertissement si ce n'est pas le cas.

10. Mode Expert STACK Avancé

Le mode Expert donne accès à tous les paramètres STACK : plusieurs champs de saisie (inputs), variables de feedback, PRT inline, barre de formatage riche.

Quand utiliser le mode Expert ?

  • Question avec plusieurs champs de saisie indépendants (ex : réel + imaginaire d'un nombre complexe)
  • Besoin de variables de feedback calculées dans le PRT (ex : calculer l'erreur relative pour un message personnalisé)
  • Paramétrage fin d'un input : interdire les décimaux, exiger la fraction irréductible, contrôle de la validation visuelle…
  • Réutilisation d'une question STACK existante avec modifications

11. Import d'une question STACK existante

StackForge peut importer une question STACK déjà exportée depuis Moodle pour en modifier le PRT.

Dans Moodle, allez dans la banque de questions, sélectionnez la question STACK et exportez-la au format Moodle XML.
Dans StackForge, cliquez sur Import XML STACK (type de question).
Sélectionnez le fichier XML. La question est importée avec tous ses PRT.
Cliquez sur PRT — nom pour ouvrir et modifier chaque arbre.
Cliquez sur Télécharger XML modifié pour exporter la version corrigée.
Si le fichier XML provient d'StackForge (il contient une signature stackforge::v1::), le projet complet est restauré automatiquement avec tous les modules.

12. Exporter vers Moodle

Assurez-vous que toutes les questions ont leur chip verte (Enregistrer appliqué).
Cliquez sur Exporter XML dans la barre d'en-tête. Un fichier stackforge-export.xml est téléchargé.
Dans Moodle : Banque de questions → Importer → Moodle XML.
Sélectionnez la catégorie cible, importez le fichier.
Testez avec Aperçu dans Moodle avant d'ajouter la question à un quiz.
Prérequis Moodle
  • Plugin STACK installé et configuré (connexion à Maxima ou Goemaxima)
  • Version Moodle ≥ 3.9, STACK ≥ 4.4
  • Droits "Créer des questions" dans la catégorie cible
  • Filtre MathJax activé pour le rendu LaTeX

14. FAQ — Erreurs courantes

Mon export XML est rejeté par Moodle avec "format invalide"

Vérifiez que vous avez sélectionné Moodle XML (et non GIFT ou Aiken) lors de l'import. Si l'erreur persiste, ouvrez le fichier dans un éditeur de texte et vérifiez qu'il commence par <?xml version="1.0" et qu'il n'y a pas de caractères parasites avant.

STACK affiche "CAS returned an error" après import

La syntaxe Maxima est incorrecte dans un champ. Causes fréquentes :

  • 2x au lieu de 2*x (multiplication implicite)
  • e^x au lieu de %e^x ou exp(x)
  • pi au lieu de %pi
  • Parenthèses non fermées ou mal balancées
  • Division par zéro possible dans une expression paramétrée
  • Virgule décimale (3,14) au lieu du point (3.14)
Les formules LaTeX n'apparaissent pas dans Moodle

Moodle doit avoir un filtre mathématiques actif. Vérifiez dans Administration → Plugins → Filtres que MathJax est activé et en position "Actif". Les formules doivent être entre \(…\) (inline) ou \[…\] (bloc centré).

L'élève répond juste mais STACK dit faux

Causes possibles selon le type de question :

  • Pour un décimal : utilisez NumRelative au lieu d'AlgEquiv
  • Pour des formes trigonométriques équivalentes : utilisez SubstEquiv
  • Pour une fraction : vérifiez que la réponse modèle est aussi réduite
  • Pour une unité physique : vérifiez que les unités SI de la réponse modèle sont correctes
  • Si vous utilisez String, vérifiez la gestion de la casse et des espaces
Les paramètres aléatoires donnent toujours la même valeur dans StackForge

L'aperçu dans StackForge affiche toujours la même valeur initiale (pour la cohérence de l'interface). Dans Moodle, chaque tentative génère de nouvelles valeurs. Pour tester plusieurs variantes, utilisez Aperçu → Commencer une nouvelle tentative dans Moodle.

La grille de mots croisés ne s'affiche pas dans Moodle
  • Plugin STACK ≥ 4.4 requis
  • JavaScript doit être activé (pas de bloqueur de scripts)
  • Si la grille est vide : ajoutez plus de mots (minimum recommandé : 6)
  • Les mots doivent partager des lettres pour se croiser
L'image du "Clic sur image" ne s'affiche pas

L'URL doit être accessible depuis le serveur Moodle :

  • Vérifiez que l'image est en ligne (pas un fichier local)
  • Le serveur hébergeant l'image doit autoriser les requêtes cross-origin (CORS)
  • Recommandé : hébergez l'image dans les fichiers du cours Moodle et utilisez l'URL interne
Comment créer une question avec plusieurs zones de saisie indépendantes ?

Utilisez le Mode Expert STACK (onglet Inputs) pour ajouter plusieurs champs (ans1, ans2…). Chaque input peut avoir son propre type et sa propre réponse modèle. Le PRT peut ensuite évaluer chaque champ séparément ou de manière combinée.

Comment écrire une inéquation comme réponse attendue ?

En Maxima : x > 2, x <= 5, -1 < x and x <= 3. Le test AlgEquiv gère les inéquations. Pour des ensembles de solutions, utilisez Sets. StackForge propose également un type dédié Inéquation.

Comment le chemin vrai du PRT doit-il totaliser 1 ?

En suivant uniquement les branches vraies depuis la racine jusqu'à un FIN, la somme des scores doit valoir 1. Exemples :

  • Nœud 0 : vrai =1 → FIN (chemin = 1) ✓
  • Nœud 0 : vrai =0.5 → Nœud 1 : vrai +0.5 → FIN (chemin = 0.5+0.5=1) ✓
  • Nœud 0 : vrai =0.7 → FIN (chemin = 0.7) ✗ — bandeau d'avertissement

Les branches fausses peuvent avoir n'importe quel score.

Mon travail a disparu après une vidange du cache du navigateur

L'autosauvegarde utilise le localStorage du navigateur, qui est effacé lors d'une vidange de cache. Pour éviter toute perte :

  • Exportez régulièrement votre projet avec Exporter projet (.stackforge)
  • Exportez également le XML Moodle comme sauvegarde de secours
  • En cas de perte, le fichier .stackforge permet une restauration complète
