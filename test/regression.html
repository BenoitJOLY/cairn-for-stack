Cairn for Stack — Tests de non-régression

Comparez le XML généré par les générateurs à une référence sauvegardée

Utilisation : Cliquez Lancer les tests pour exécuter les générateurs avec des données fixes et comparer au snapshot de référence. Si c'est la première fois (ou après un changement voulu), cliquez Enregistrer comme référence pour sauvegarder l'état actuel. Les références sont stockées dans localStorage.
